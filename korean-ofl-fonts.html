05 · 설치

윈도우
  1. zip 오른쪽 클릭 → 모두 압축 풀기
  2. 폰트 폴더를 열고 Ctrl+A
  3. 오른쪽 클릭 → 추가 옵션 표시 → 설치
Windows 10은 오른쪽 클릭 메뉴에 바로 「설치」
맥
  1. zip을 더블클릭해 풀기
  2. 서체 관리자(Font Book) 열기
  3. 폰트 폴더를 창에 끌어다 놓기
